# Phase 1 – Requirement Analysis & Planning

This phase defines the requirements, business scenario, objectives, and planned incident lifecycle for the ServiceNow Incident Lifecycle Automation project.

## Business Scenario

A user is unable to connect to the company VPN even though internet connectivity is available.

## Planned Lifecycle

Create → Classify → Prioritize → Assign → Investigate → Knowledge → Escalate → Change → Child Incident → Resolve → Validate

## Objective

To design and plan an end-to-end ServiceNow incident lifecycle before implementation.
